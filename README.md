# Simple Election Voting System

This is my second Python project. It is a simple command-line
election voting system created using Python.

## Features

- Users Allow to put the Candidates names and their voting numbers are auto displayed by the system.
- Allow users to vote
- Count votes
- Display the election result
- Handle invalid candidate choices

## Technologies Used

- Python
